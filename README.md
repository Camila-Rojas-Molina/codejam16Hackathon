# Travel Quest

A geohunting app that pairs tourists with locals. Teams find the place in a photo before time runs out, visit it together, and take a selfie to earn points.

## Repo layout

```
.
├── claude/        Instructions for Claude Code (claude.md)
├── frontend/      React + TypeScript + Tailwind web app (start here)
├── backend/       API (not started)
└── (static assets live in frontend/public/assets)
```
