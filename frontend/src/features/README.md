# Features

One folder per product area. Each feature keeps its own types, logic and UI together.

- `quests/`: photo hunts, time limits, selfie check-in
- `scoring/`: point rules (first finder earns the most)
- `teams/`: tourist and local teams, team score
- `dogs/`: local and tourist dog park matches with bonus points
- `accessibility/`: needs-based place recommendations
- `map/`: Google Maps helpers and shared coordinate types
