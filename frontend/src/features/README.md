# Features

One folder per product area. Each feature keeps its own types, logic and UI together.

- `onboarding/`: account creation options and the universal questionnaire (both sections + summary rows)
- `profile/`: one account, two modes. Profile data model, privacy rules, matching inputs, mode switching
- `chat/`: discovering people, conversations, the recent-message preview
- `rewards/`: points balance and the shop catalogue (accessories for Migo)
- `quests/`: challenges (daily, starter…) with progress and rewards (`challenges.ts`), plus photo hunts, time limits, selfie check-in
- `scoring/`: point rules (first finder earns the most)
- `teams/`: tourist and local teams, team score
- `dogs/`: local and tourist dog park matches with bonus points
- `accessibility/`: needs-based place recommendations
- `map/`: Google Maps helpers and shared coordinate types
